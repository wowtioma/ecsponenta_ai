# Экспонента · Синоникс

Ветка `с` содержит пользовательский интерфейс системы. Он обеспечивает взаимодействие с ИИ-ассистентом, позволяет описывать обмен данными между двумя сетями, отвечать на уточняющие вопросы и просматривать результаты расчёта. Интерфейс разделяет процесс общения с ассистентом и отображение полученной конфигурации.

## Что реализовано

- **Основной интерфейс.** Приложение построено на React и TypeScript с использованием Tailwind CSS. Рабочая область разделена на две части: слева располагается чат с ИИ-ассистентом, справа — панель результатов.
- **Чат с ассистентом.** Пользователь может описать задачу обычным текстом, отправить сообщение и получить ответ. Предусмотрена подстановка демонстрационного примера для проверки работы системы.
- **Уточняющие вопросы.** Ответы ассистента отображаются в виде интерактивных блоков с вариантами выбора. Пользователь может выбрать предложенный вариант, указать «Не знаю» или ввести собственный ответ через вариант «Другое».
- **Отображение результатов.** Правая панель содержит отдельные вкладки для просмотра объяснения, таблицы правил и схемы размещения. Это позволяет изучать результат расчёта в удобном формате, не переключаясь между разными страницами.
- **Таблица правил.** Правила передачи отображаются с указанием типа обмена, направления, режима передачи, протокола, порта и описания. Поддерживается отображение как обычных текстовых протоколов, так и параметров, различающихся для открытой и закрытой сетей.
- **Предварительный просмотр схемы.** Реализован компонент `DiagramPreview`, который визуально отображает открытую и закрытую сети, подключённые устройства, межсетевой экран и ПАК «Синоникс» с тремя основными элементами: Узел А, Ядро и Узел В. Дополнительно отображаются потоки передачи и их основные параметры.
- **Редактор схемы draw.io.** Вкладка «Схема» открывает схему не картинкой, а в полноценном редакторе draw.io (`embed.diagrams.net` во встроенном фрейме): блоки сетей, устройств, межсетевого экрана и «Синоникса» можно перетаскивать, переименовывать и перекрашивать прямо на сайте. Правки автоматически сохраняются в браузере (localStorage) и переживают перезагрузку; кнопка «Скачать .drawio» выгружает именно отредактированную схему, «Сбросить» возвращает схему, построенную по результату расчёта. Переключатель «Редактор / Просмотр» оставляет статичную схему как запасной вариант: если редактор не загрузился (нет доступа к `embed.diagrams.net`), показывается сообщение и кнопки «Попробовать снова», «Статичная схема» и «Скачать .drawio». Адрес редактора можно переопределить переменной окружения `VITE_DRAWIO_EMBED_URL` (в том числе для self-hosted draw.io за тем же доменом).
- **Управление сессией.** Предусмотрена возможность начать новую сессию, сбросив текущее состояние интерфейса. Во время работы также отображается время выполнения последнего шага и среднее время обработки запросов.
- **Чёрно-белая тема.** Интерфейс оформлен в монохромной палитре. В шапке есть переключатель светлой и тёмной темы; выбор сохраняется в `localStorage` и применяется до первой отрисовки, поэтому страница не мигает белым.
- **Расходы на сессию.** Внизу слева, под полем ввода чата, показываются суммарные токены и стоимость за сессию. По нажатию раскрывается детализация: входные и выходные токены, стоимость входа и выхода, оценочная и фактическая стоимость, число вызовов модели и список моделей. Если фактическая стоимость не пришла, выводится «Не подтверждено»; малые суммы не округляются до $0,00. При старте новой сессии счётчик обнуляется.
- **Регулировка правой панели.** Ширину панели результатов можно менять перетаскиванием разделителя мышью, кнопками «−» и «+» на разделителе или стрелками клавиатуры (Home — вернуть ширину по умолчанию). Разделитель также позволяет свернуть панель в узкую полосу и развернуть её обратно; ширина и состояние сохраняются между перезагрузками.
## Веб-версия (статический демо-сайт)

Ветка `С` собирается в статический сайт, которому не нужен бэкенд: ответы ассистента формируются демо-сценариями из `frontend/src/mocks.ts` (демо-режим включается `VITE_USE_MOCK=true`, в шапке появляется метка «демо»). Публикация — GitHub Pages через workflow `.github/workflows/pages.yml`.

- **Публикация:** Settings → Pages → Build and deployment → Source: **GitHub Actions**. После этого каждый пуш в ветку `С` пересобирает и публикует сайт.
- **Адрес:** `https://wowtioma.github.io/ecsponenta_ai/`
- **Как собирается:** `frontend` собирается с `VITE_USE_MOCK=true` и `VITE_BASE_PATH=/ecsponenta_ai/` (подпуть GitHub Pages), затем артефакт `frontend/dist` отдаётся на Pages.
- **Локально так же:** `cd frontend`, затем `VITE_USE_MOCK=true` и `VITE_BASE_PATH=/ecsponenta_ai/` в переменных окружения, `npm run build`, `npm run preview` → `http://localhost:4173/ecsponenta_ai/`.
- **Ограничения демо:** ИИ-ответы — заранее заготовленные сценарии (насосная станция, файловый обмен, USB), правила по-настоящему не рассчитываются; редактор схемы draw.io требует доступа к `embed.diagrams.net` (иначе аварийный экран и статичная схема); правки схемы хранятся в браузере пользователя.
- **Приватный репозиторий:** GitHub Pages для приватных репозиториев доступен на платных планах (Pro/Team) — либо сделайте репозиторий публичным.
