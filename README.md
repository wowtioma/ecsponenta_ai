# Экспонента · Синоникс

Ветка `A` содержит ядро расчёта. Оно принимает структурированное описание обмена между двумя сетями, рекомендует размещение межсетевого экрана и «Синоникса», рассчитывает правила и формирует уточняющие вопросы. Расчёт работает локально и даёт одинаковый результат для одинакового входа.

## Что реализовано

- **Состояние сессии.** `Session` хранит сети, потоки, явно согласованные допущения и ответы на уточнения. Неизвестные параметры попадают в `unknowns`, согласованные решения — в `assumptions`.
- **Размещение.** Рекомендуемая цепочка проходит от открытой сети через МЭ и «Синоникс» к закрытой сети. Узел А обращён к открытой стороне, Узел В — к закрытой. USB подключается к Узлу А и на диаграмме проходит мимо МЭ.
- **Расчёт данных.** Потоки с общим получателем, портом и протоколом могут использовать одно правило. MQTT, Modbus TCP и МЭК‑104 требуют двунаправленного правила. NTP рассчитывается как одно однонаправленное правило и выгружается как UDP. При превышении 256 правил ядро возвращает ограничение и сохраняет полный расчёт.
- **Расчёт файловых потоков.** Ядро учитывает проверки на каждой стороне, видимость принятых файлов и совместимость настроек PULL/PUSH. В счётчике файловых пользователей один человек учитывается один раз по идентификатору, каждое правило с PULL добавляет одного технического пользователя, PUSH дополнительных пользователей не добавляет.
- **Уточнения и выгрузка.** Вопросы содержат варианты «Не знаю» и «Другое». Служебный результат версии `1.1` содержит размещение, правила, счётчики и статус `needs_clarification`, `preliminary`, `completed` или `unsupported`.
