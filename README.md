# Экспонента · Синоникс

Ветка `ui` содержит пользовательский интерфейс системы. Он обеспечивает взаимодействие с ИИ-ассистентом, позволяет описывать обмен данными между двумя сетями, отвечать на уточняющие вопросы и просматривать результаты расчёта. Интерфейс разделяет процесс общения с ассистентом и отображение полученной конфигурации.

## Что реализовано

- **Основной интерфейс.** Приложение построено на React и TypeScript с использованием Tailwind CSS. Рабочая область разделена на две части: слева располагается чат с ИИ-ассистентом, справа — панель результатов.
- **Чат с ассистентом.** Пользователь может описать задачу обычным текстом, отправить сообщение и получить ответ. Предусмотрена подстановка демонстрационного примера для проверки работы системы.
- **Уточняющие вопросы.** Ответы ассистента отображаются в виде интерактивных блоков с вариантами выбора. Пользователь может выбрать предложенный вариант, указать «Не знаю» или ввести собственный ответ через вариант «Другое».
- **Отображение результатов.** Правая панель содержит отдельные вкладки для просмотра объяснения, таблицы правил и схемы размещения. Это позволяет изучать результат расчёта в удобном формате, не переключаясь между разными страницами.
- **Таблица правил.** Правила передачи отображаются с указанием типа обмена, направления, режима передачи, протокола, порта и описания. Поддерживается отображение как обычных текстовых протоколов, так и параметров, различающихся для открытой и закрытой сетей.
- **Предварительный просмотр схемы.** Реализован компонент `DiagramPreview`, который визуально отображает открытую и закрытую сети, подключённые устройства, межсетевой экран и ПАК «Синоникс» с тремя основными элементами: Узел А, Ядро и Узел В. Дополнительно отображаются потоки передачи и их основные параметры.
- **Управление сессией.** Предусмотрена возможность начать новую сессию, сбросив текущее состояние интерфейса. Во время работы также отображается время выполнения последнего шага и среднее время обработки запросов.
