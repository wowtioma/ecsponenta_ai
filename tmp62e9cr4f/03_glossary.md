# Глоссарий

Термины, которые встречаются в материалах о «Синониксе» и в сценариях кейса.

## Сети и защита

| Термин | Что это |
| --- | --- |
| Сеть, сегмент | Группа компьютеров и устройств, которые обмениваются данными напрямую. В кейсе слова «сеть» и «сегмент» означают одно и то же |
| Закрытый сегмент | Сеть с повышенными требованиями к защите, которую нельзя напрямую соединять с другими сетями. Например, сеть цеха или сегмент с хранилищем резервных копий |
| Открытая сеть | Менее доверенная сеть. Например, офисная сеть с выходом в интернет |
| МЭ, межсетевой экран | Средство защиты на границе сетей. Пропускает или блокирует сетевой трафик по заданным правилам: адресам, портам, протоколам |
| NGFW | Next-Generation Firewall, межсетевой экран нового поколения. Помимо адресов и портов анализирует содержимое трафика и распознаёт приложения |
| IP-адрес | Числовой адрес устройства в сети, по которому ему доставляются данные |
| Порт | Число от 0 до 65535, по которому на устройстве определяется сетевая служба или приложение, принимающее данные. Например, приём журналов Syslog по UDP обычно идёт на порт 514 |
| TCP | Transmission Control Protocol. Транспортный протокол с установлением соединения, подтверждением доставки и сохранением порядка данных |
| UDP | User Datagram Protocol. Транспортный протокол без установления соединения и без подтверждения доставки |
| Data Diode, диод данных | Устройство, которое на аппаратном уровне пропускает данные только в одну сторону и не анализирует передаваемую информацию. Смежный класс решений, с которым сравнивают «Синоникс» |
| Точка-точка | Соединение между двумя конкретными системами, заданными адресом и портом, а не между сетями целиком |

## «Синоникс»

| Термин | Что это |
| --- | --- |
| СКИО | Система (средство) контроля информационного обмена. Класс продуктов, к которому относится «Синоникс» |
| ПАК | Программно-аппаратный комплекс: программное обеспечение, которое поставляется вместе с предназначенным для него оборудованием |
| Узел А, Узел В | Две платы «Синоникса». Каждая подключена только к своей сети |
| Ядро | Центральная плата «Синоникса» между Узлами. Только через неё данные попадают с одного Узла на другой |
| Поток | Одна передача: что передаётся, от кого, кому, по какому протоколу и порту |
| Правило | Разрешение на один поток. Создаётся на обоих Узлах двумя администраторами |
| collect | Режим правила передачи данных на Узле со стороны отправителей. Узел принимает данные на свой адрес и порт |
| exchange | Режим правила передачи данных на втором Узле. Узел передаёт данные на адрес и порт конечной системы |
| Однонаправленное правило | Правило, по которому данные идут только в одну сторону, а ответные пакеты не доставляются. В материалах «АйТи Бастиона» также называется программным диодом |
| Двунаправленное правило | Правило, по которому обмен идёт в обе стороны |
| Профиль проверок | Набор проверок файлов, привязанный к правилу передачи файлов |
| Физический (пусковой) ключ | Ключ на лицевой панели устройства. Поворот ключа отключает Ядро и останавливает весь обмен |
| Программный ключ | Остановка обмена удалённо, с рабочего места администратора. Отключает либо передачу данных, либо передачу файлов, либо и то и другое. В одной из новостей «АйТи Бастиона» назван «электронным ключом» |

## Передача файлов

| Термин | Что это |
| --- | --- |
| SFTP | SSH File Transfer Protocol. Протокол передачи файлов поверх защищённого соединения SSH: и учётные данные, и файлы передаются в зашифрованном виде |
| FTP | File Transfer Protocol. Протокол передачи файлов между клиентом и сервером поверх TCP. Учётные данные и файлы передаются без шифрования |
| SMB | Server Message Block. Сетевой протокол прикладного уровня для удалённого доступа к файлам, каталогам и другим общим ресурсам. Основной протокол общих папок в Windows |
| PULL | Узел «Синоникса» сам по расписанию забирает файлы из хранилища |
| PUSH | Узел «Синоникса» сам доставляет файл в хранилище, как только файл на него поступил |
| Файловое хранилище, файловый сервер | Сервер с общими каталогами, куда кладут и откуда забирают файлы |
| Маска имени | Шаблон, которому должно соответствовать имя файла. Например, `update_*.zip` |
| Контроль целостности | Проверка того, что файл не был изменён или повреждён. В «Синониксе» файл подписывается, а при проверке его контрольная сумма сверяется с подписью с помощью публичной части ключа |
| ICAP | Internet Content Adaptation Protocol. Протокол, по которому одна система передаёт содержимое (например, файл) на проверку другой системе и получает решение. По нему «Синоникс» отправляет файлы во внешние средства проверки |
| Антивирус (AV) | Средство обнаружения вредоносного кода в файлах |
| Песочница (Sandbox) | Система, которая запускает файл в изолированной среде и анализирует его поведение, чтобы выявить вредоносную активность |
| DLP | Data Loss Prevention, система предотвращения утечек данных. Анализирует передаваемые данные и файлы по заданным политикам, фиксирует или блокирует передачу конфиденциальной информации |

## Системы из сценариев

| Термин | Что это |
| --- | --- |
| Журналы событий | Записи о событиях в системе: входы пользователей, ошибки, изменения настроек |
| Syslog | Стандартный протокол передачи сообщений журналов по сети |
| SIEM | Security Information and Event Management. Система, которая собирает события безопасности из разных источников, сопоставляет их и выявляет инциденты |
| SOC | Security Operations Center, центр мониторинга безопасности: подразделение, которое отслеживает события и реагирует на инциденты |
| NTP | Network Time Protocol. Протокол синхронизации времени устройств с сервером времени |
| Телеметрия | Показания, которые оборудование передаёт автоматически: давление, температура, состояние |
| АСУ ТП | Автоматизированная система управления технологическим процессом. Комплекс программных и технических средств (датчики, контроллеры, серверы, рабочие места операторов) для контроля и управления технологическим оборудованием на производстве и объектах инфраструктуры |
| ПЛК, контроллер | Программируемый логический контроллер. Промышленное устройство, которое по заданной программе управляет оборудованием и собирает с него данные |
| SCADA | Supervisory Control and Data Acquisition. Программный комплекс диспетчерского управления и сбора данных: показывает оператору состояние оборудования и позволяет им управлять |
| Modbus TCP | Промышленный протокол обмена данными по модели «клиент-сервер» поверх TCP. Клиент читает и записывает значения регистров контроллера. Стандартный порт 502 |
| Регистр | Ячейка в памяти контроллера с одним значением. Например, температура или команда пуска |
| MQTT | Message Queuing Telemetry Transport. Протокол обмена сообщениями по модели «издатель-подписчик» поверх TCP. Издатель публикует сообщения в топик на брокере, брокер доставляет их подписчикам этого топика. Широко применяется для передачи телеметрии |
| MQTT-брокер | Сервер MQTT, который принимает сообщения от издателей и рассылает их подписчикам |
| Топик | Иерархическое имя темы сообщений в MQTT. Например, `цех1/насос2/давление` |
| МЭК 104 | МЭК 60870-5-104. Протокол телемеханики поверх TCP: передаёт измерения, сигналы и команды между диспетчерским центром и оборудованием объекта. Стандартный порт 2404 |
| Резервная копия, бэкап | Копия данных, из которой их можно восстановить при потере |
| СХД | Система хранения данных: оборудование с дисками для хранения больших объёмов данных, например резервных копий |
| PAM, СКДПУ НТ | Privileged Access Management, система контроля привилегированного доступа: проверяет, кто подключается к системам, и записывает его действия. СКДПУ НТ - PAM-система от компании «АйТи Бастион» |
| КИИ | Критическая информационная инфраструктура: системы, сбой которых опасен для людей, экономики или государства |
| ФСТЭК России | Федеральная служба по техническому и экспортному контролю. Устанавливает требования по защите информации и сертифицирует средства защиты |
