# База знаний кейса «ИИ-ассистент по размещению Синоникса»

Сведения о «Синониксе» ассистент берёт только из этих файлов. Актуальная версия продукта для кейса: 1.9.


| Файл                                             | Что внутри                                                                                                                                        |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `01_scope_functions_synonyx_1.9.md`              | Факты о продукте с указанием источника у каждого факта                                                                                            |
| `02_methodology.md`                              | Как ассистент размещает «Синоникс», считает правила, какие вопросы задаёт, формат ответа (текст, файл .drawio, служебный JSON) и оформление схемы |
| `03_glossary.md`                                 | Термины и сокращения простыми словами                                                                                                             |
| `04_benchmarks.json`                             | 9 примеров запросов с эталонными ответами. Решения оцениваются на полном наборе, которого здесь нет; формат в нём такой же                        |
| `05_pattern_F02.drawio`, `05_pattern_F07.drawio` | Образцы готовых схем для запросов F02 и F07 из открытых примеров                                                                                  |
| `06_template.drawio`                             | Готовые элементы схемы: ассистент копирует их и меняет подписи                                                                                    |
| `07_photo_pak_panel.png`                         | Фото лицевой панели устройства (справочно)                                                                                                        |
| `Сценарии_Синоникс.docx`                         | Сценарии применения Синоникс с описанием и схемами                                                                                                |
| `Синоникс_Техническая.pdf`                       | Презентация продукта Синоникс                                                                                                                     |
| `Синоникс_сравнение классов решений.pdf`         | Брошюра сравнение Синоникса со смежными классами решений МЭ, NGFW и дата диодами                                                                  |
| `Синоникс сценарии и новые возможности для энергетики.pdf`         | Презентация применения Синоникса в энергетике  

Файлы `.drawio` открываются на сайте app.diagrams.net или в программе draw.io.
